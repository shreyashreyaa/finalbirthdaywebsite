Netlify Private Deploy (drag-and-drop)

1) Set the site password locally before building (recommended):

Create a file named `.env` at the project root with:

VITE_SITE_PASSWORD=your_shared_password

2) Install and build locally:

```bash
npm install
npm run build
```

3) Deploy to Netlify (no repo required):
- Open https://app.netlify.com/drop
- Drag the `dist` folder (generated by the build) onto the page.

4) To change the password after deployment:
- In Netlify site dashboard → Site settings → Build & deploy → Environment → Edit variables
- Add `VITE_SITE_PASSWORD` with your new password and trigger a redeploy.

Notes & security:
- This site uses a client-side passcode gate (the passcode is required to unlock the UI). Static assets are still publicly accessible by direct URL. For stronger privacy, consider deploying from a private Git repo and using Netlify Access/Identity (team or paid features) or a server-side auth solution.
